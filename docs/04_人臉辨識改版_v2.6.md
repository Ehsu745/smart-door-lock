# v2.6 人臉辨識改版：LBPH → YuNet + SFace

2026-11-05 ～ 11-07

## 1. 起因

2026-11-05 學弟 demo 時，系統把現場一位陌生人認成成員 `eric`（訪客）。當時 `eric` 本人不在現場。

先前也發現 `eric` 不戴眼鏡時系統認不出來，所以一開始懷疑是眼鏡造成的。

## 2. 分析

舊做法是 Haar 找臉，再用 LBPH 辨識，距離 < 70 算認得。

- **LBPH 只能從名單裡挑人**：它只回答「最像名單裡的誰」，能不能擋下陌生人，完全靠距離門檻。
- **「連續 8 幀」擋不住誤認**：同一個人連續幾幀的分數幾乎一樣，第一幀誤認，後面通常也會跟著誤認。
- **如果被誤認成主人（master）**，就會進到手勢階段，而手勢誰都能比。所以這不只是誤發通知，而是有開鎖風險。

## 3. 比較實驗

| 項目 | 內容 |
|---|---|
| 本人 | `faces/` 30 張照片（同一次拍的，戴眼鏡），每次拿掉一張，跟剩下 29 張比 |
| 陌生人 | 公開人臉資料集 LFW，每人 1 張，共 5,524 人。處理方式跟門鎖相同：Haar 裁臉、轉灰階 |
| 判定方式 | 單幀；跟 30 張照片比，取最像的一張 |

### 結果

| | LBPH（舊） | YuNet + SFace（新） |
|---|---|---|
| 本人最差分數 | 距離 46.4 | 相似度 0.840（距離 16） |
| 最像本人的陌生人 | 距離 56.1 | 相似度 0.462（距離 54） |
| 舊門檻 70 的誤認率 | **8.60%**（475 人） | — |
| 收緊門檻後的誤認率 | 0.16%（門檻 60） | **0 / 5,524**（門檻 50）＊ |
| 每張臉耗時（Mac） | 1.6 ms | 7.1 ms |

- **LBPH 沒有安全的門檻**：本人跟最像的陌生人只差 10 分，而本人實際在門口時距離常在 50～70 之間跳動（見 CLAUDE.md 已知問題）。
- **SFace 分得很開**：本人跟陌生人差了 0.38。
- **端對端測試**：把臉貼進 640×480 畫面，走完整個辨識流程。1,000 位陌生人在門檻 55 時誤認 1 位（距離 52.8），所以預設門檻定在 50。
- ＊**0 次不等於 0%**：依 rule of three，5,524 人全數擋下只能說誤認率的 95% 信心上限約 3 ÷ 5,524 ≈ **0.054%**；端對端 1,000 人在門檻 50 全擋下，上限約 **0.3%**。報告裡請寫上限，不要寫 0%（見 `docs/05_資料污染與判定標準.md` 第 7 節）。

### 眼鏡只對了一半

把 LBPH 誤認最嚴重的 24 位陌生人拼成圖來看，**大多數沒戴眼鏡**，膚色、性別、年齡也都不一樣。所以主因是 LBPH 本身分辨能力不足，眼鏡是次要因素。

「不戴眼鏡就認不出來」這點仍然成立，原因是 30 張照片全部戴同一副眼鏡。

### 這次實驗的限制

- **本人通過率 100% 過於樂觀**：30 張照片是幾秒內連拍的，幾乎一模一樣。
- **LFW 是網路上的彩色照片**，跟 NoIR 相機或 webcam 拍的畫面不同。
- **還要在實際環境量本人的距離**：換一天、在門口光線下，戴與不戴眼鏡各拍一組，只拿來測試，不拿來登錄。

## 4. 新做法

| | 說明 |
|---|---|
| 找臉 | **YuNet**（OpenCV 內建 `cv2.FaceDetectorYN`），同時輸出 5 個五官點 |
| 認人 | **SFace**（`cv2.FaceRecognizerSF`）：依五官點對齊成 112×112，轉成 128 維特徵 |
| 登錄（`train`） | 不訓練神經網路（SFace 已用大量資料訓練好），只把 `faces/` 每張照片轉成特徵，存成 `face_feats.npz` |
| 比對 | 跟所有登錄的特徵算 cosine 相似度，取最像的一張 |
| 距離 | `(1 − cosine) × 100`，越小越像。沿用舊介面（`distance < threshold` 算認得），網頁、哨兵、資料庫都不用改 |
| 門檻 | 預設 `FACE_THRESHOLD=50`（cosine 0.5） |

### 資料量

| 項目 | 大小 |
|---|---|
| 30 張照片 | 220 KB |
| LBPH `face.yml` | 3.98 MB，每多一張照片多 0.13 MB，比對時間也跟著變長 |
| SFace 特徵 | 每張 512 bytes，30 張 16 KB。存 1 萬張也只有約 5 MB，比對不到 1 ms |
| 模型 | YuNet 0.23 MB、SFace 38.7 MB |

Pi 上真正花時間的是每一幀的找臉和算特徵，跟登錄了幾張照片無關。

## 6. 相容性與升級

- **不用重拍**：第一次啟動時，沒有 `face_feats.npz` 就自動用 `faces/` 的照片建立，主人 / 訪客設定不變。
- **模型自動下載**到 `models/`，下載後核對檔案檢查碼。Pi 沒有網路時，可以先用 `curl` 下載後放進去（網址在 `config.py`）。
- **OpenCV 需要 4.8 以上**。版本不夠時會顯示明確的錯誤訊息。
- **舊模型檔不刪**：`face.yml` 已不再使用，但保留在原地。
- **⚠️ 設定檔要改**：如果 `smartlock.env` 有 `FACE_THRESHOLD=70`，**一定要拿掉**。距離的定義已經變了，沿用 70 會非常寬鬆。
