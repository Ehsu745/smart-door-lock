# 硬體接線

依據 `arduino/door_lock/door_lock.ino`（學弟寫的 sketch，已實測可開關鎖）整理。
**鎖的實際型號、電壓，以及接在 NO 還是 NC，還沒和學弟確認**：見最後「待確認」。

## 架構

```
Pi Camera 3 NoIR ─(CSI 排線)─▶ Raspberry Pi 5 ─(USB-A ↔ USB-B)─▶ Arduino UNO ─(D7)─▶ 繼電器模組 ─(COM/NO)─▶ 電磁鎖
                                                                                                   ▲
                                                                              鎖的獨立電源（通常 12V DC）
```

- Pi 和 UNO 之間只有**一條 USB 線**：同時負責序列通訊（9600 baud）和 UNO 的供電。
- 繼電器和鎖不經過 Pi 的 GPIO，Pi 只透過序列埠送文字指令。

## 接線表

| 從 | 到 | 說明 |
|---|---|---|
| Pi USB-A | UNO USB-B | 序列埠，Pi 上通常是 `/dev/ttyACM0`；也供電給 UNO |
| UNO 5V | 繼電器 VCC | |
| UNO GND | 繼電器 GND | |
| UNO **D7** | 繼電器 IN | `RELAY_PIN = 7` |
| 12V 電源 ＋ | 繼電器 COM | |
| 繼電器 **NO** | 鎖 ＋ | 假設鎖是「通電開」；磁力鎖要改接 NC（見下方） |
| 鎖 － | 12V 電源 － | |
| 二極體 1N4007（建議加） | 並聯在鎖兩端 | 白線（陰極）接 ＋，吸收線圈斷電的反向高壓 |

```

   5V  ───────────────────────▶  VCC
   GND ───────────────────────▶  GND
   D7  ───────────────────────▶  IN

 繼電器（接點端）                電磁鎖                 鎖的電源（12V DC）
   COM ◀──────────────────────────────────────────────  ＋
   NO  ───────────────────────▶  ＋
                                 － ──────────────────▶  －
```

## sketch 的行為

| 項目 | 值 |
|---|---|
| 控制腳 | D7 |
| 觸發方式 | **低電位觸發**：`RELAY_ON = LOW`、`RELAY_OFF = HIGH`（常見的藍色光耦繼電器模組） |
| 開機狀態 | 先寫 HIGH 再設 OUTPUT → 開機不會誤觸發開鎖 |
| 指令 | 以 `\n` 或 `\r` 結尾，不分大小寫：`unlock`、`lock` |
| 回覆 | `Unlocked: auto-lock in 8 seconds`、`Locked`；看不懂的指令回 `Unknown command: use unlock or lock`；開機印 `Ready: enter unlock or lock` |
| 自動上鎖 | 開鎖 8 秒後（`UNLOCK_DURATION = 8000`） |

Python 端對應：`smartlock/arduino.py`。
- 送小寫指令加 `\n`。
- 開埠後等 2 秒，因為 UNO 開序列埠時會自動重置。
- 送指令前先清空接收緩衝區。
- `ARDUINO_STRICT=1`（預設）時一定要收到回覆才算成功；錯誤訊息裡的 `unlock` 字樣不算確認。
- `unlock_seconds = 8` 要和 sketch 的 `UNLOCK_DURATION` 一致，網頁倒數才會準。

## 注意事項

1. **NO / NC 依鎖的種類決定**（sketch 的設計是「繼電器吸合＝開鎖」）

   | 鎖的種類 | 特性 | 接 |
   |---|---|---|
   | 電磁鎖舌、陰極鎖、櫃鎖 | 斷電上鎖、通電開（fail-secure） | **NO** |
   | 磁力鎖（大吸盤） | 通電吸住、斷電開（fail-safe） | **NC** |

   接反了結果會剛好相反：平常門是開的，送 `unlock` 反而上鎖。

2. **鎖不能用 Arduino 或 Pi 供電**：電磁鎖通常要 12V、0.5～1A，要用獨立的變壓器。
3. **12V 的負極不要接到 Arduino GND**：繼電器已經把兩邊隔開，兩組電源分開，雜訊比較少。
4. **JD-VCC 跳線帽**（如果模組上有）保持插著，由 UNO 的 5V 供電。
5. **Pi 用 5V/5A 電源**：UNO 和繼電器都從 Pi 的 USB 取電，電源不足時，繼電器動作可能讓系統不穩。
6. **鎖的兩端並二極體**：沒加的話，繼電器接點容易跳火花，嚴重時會干擾 UNO 造成重置（Python 端會看到 Arduino 斷線又重連）。

## 測試步驟

1. **只接 Pi、UNO、繼電器，先不接鎖**：
   ```bash
   python app.py test-arduino      # 會送 LOCK → UNLOCK → LOCK
   python serial_diag.py           # 序列埠更細的診斷（波特率、換行、回覆）
   ```
   正常的話：繼電器「喀」一聲，模組上的燈亮 8 秒後熄滅。
2. **用三用電表量繼電器接點**：COM–NO 平常不通，送 `unlock` 後 8 秒內導通。
3. **量鎖的電源**：確認是 12V，正負極沒有接反。
4. **接上鎖做完整測試**：`python app.py run`。

## 疑難排解

| 現象 | 可能原因 |
|---|---|
| `test-arduino` 找不到埠 | USB 線只能充電、不能傳資料；或要用 `ARDUINO_PORT=/dev/ttyACM0` 指定 |
| 有開埠但一直沒有回覆 | sketch 沒燒進去、波特率不是 9600；可以先用 `ARDUINO_STRICT=0` 確認是不是只差回覆 |
| 繼電器燈有亮，但鎖不動 | 鎖的電源沒接或電壓不夠、接到 NC、鎖的正負接反 |
| 平常是開的，`unlock` 反而上鎖 | NO / NC 接反，或鎖是磁力鎖（要接 NC） |
| 繼電器動作時 Arduino 斷線重連 | 沒加二極體、Pi 電源不足、12V 和 5V 的地線接在一起產生雜訊 |
| 開機瞬間鎖跳開一下 | 繼電器模組是高電位觸發（跟 sketch 的設定相反）；確認模組型號，必要時對調 `RELAY_ON` / `RELAY_OFF` |
